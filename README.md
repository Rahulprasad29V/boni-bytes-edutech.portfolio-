## 🎯 Features

### 🌙 Design & UI
- ✅ **Dark/Light Mode** – Toggle between themes with smooth transitions
- ✅ **Premium Animations** – Framer Motion style animations (particles, cursor glow, scroll effects)
- ✅ **Responsive Design** – Optimized for desktop, tablet, and mobile
- ✅ **Modern UI** – Glass-morphism, gradients, and clean typography
- ✅ **Custom Cursor Glow** – Interactive cursor effect

### 📱 Portfolio
- ✅ **12 Demo Projects** – Complete with detailed information
- ✅ **Project Filter System** – Filter by category (Web, CRM, Healthcare, etc.)
- ✅ **Project Modal** – Click to view full project details
- ✅ **Dashboard Images** – Professional project previews

### 💬 Communication
- ✅ **WhatsApp Integration** – All "Book Consultation" buttons
- ✅ **WhatsApp Floating Button** – Always visible
- ✅ **Pre-filled Messages** – Auto-populated consultation requests
- ✅ **Contact Form** – Working with EmailJS
- ✅ **Social Media Icons** – WhatsApp, LinkedIn, Instagram, GitHub

### 📄 Pages Included
- Home
- Services (6 service cards)
- Portfolio (12 projects with filters)
- Testimonials (3 client reviews)
- Pricing (3 plans)
- FAQ (4 questions)
- Contact / Get in Touch
- Footer with all links
